> 以下三个案例均为脚本真实运行输出（基于 `references/menu-data.json` 离线演示数据）。

python3 scripts/price_optimizer.py --budget 30

   · 双层吉士堡  ¥16.50  [主食]
   · 大可乐  ¥11.50  [饮料]

🥉 方案 3｜合计 ¥29.50｜综合得分 20（满足度 12 + 完整度 8）｜性价比 0.41 分/元 🥤 轻食档

若叠加优惠券（满 30 差 ¥1.5），可提示用户「加个小薯条凑满 30 减 5」。

## 案例二：巨无霸信徒 —— 预算 ¥50

**用户输入**：「想吃巨无霸，50 块钱，怎么点最划算」

```bash
python3 scripts/price_optimizer.py --budget 50 --must big_mac
```

**输出**：

```
🍔 麦麦省钱助手｜预算 ¥50.00｜必点 ['big_mac']｜排除 无

[提示] 「巨无霸」已自动升级为「巨无霸套餐」（套餐比单点省 ¥7.50）

🥇 方案 1｜合计 ¥45.50｜综合得分 32（满足度 21 + 完整度 11）｜性价比 0.46 分/元 🍽️ 完整正餐
   · 巨无霸套餐  ¥39.50  [套餐] （比单点省 ¥7.50）
   · 圆筒冰淇淋  ¥6.00  [甜品]

🥈 方案 2｜合计 ¥47.50｜综合得分 31（满足度 20 + 完整度 11）｜性价比 0.42 分/元 🍽️ 完整正餐
   · 巨无霸套餐  ¥39.50  [套餐] （比单点省 ¥7.50）
   · 香甜玉米杯  ¥8.00  [小食]

🥉 方案 3｜合计 ¥39.50｜综合得分 28（满足度 17 + 完整度 11）｜性价比 0.43 分/元 🍽️ 完整正餐
   · 巨无霸套餐  ¥39.50  [套餐] （比单点省 ¥7.50）
```

**解读**：这是本 Skill 的核心场景——用户只说"想吃巨无霸"，
算法自动把单品升级为套餐（薯条+饮料白送，立省 ¥7.50），
剩余预算再补一个冰淇淋。**单点思维 vs 套餐思维的差价，就是省出来的钱。**

## 案例三：预算不足的风控 —— 必点巨无霸但只有 ¥20

**用户输入**：「想吃巨无霸，但我只有 20 块」

```bash
python3 scripts/price_optimizer.py --budget 20 --must big_mac
```

**输出**：

```
🍔 麦麦省钱助手｜预算 ¥20.00｜必点 ['big_mac']｜排除 无

[提示] 必选项合计 ¥25.50 已超预算 ¥20.00，结果将超支，请确认

🥇 方案 1｜合计 ¥25.50｜综合得分 16（满足度 10 + 完整度 6）｜性价比 0.39 分/元 🥤 轻食档 ⚠️ 超预算
   · 巨无霸  ¥25.50  [主食]
```

**解读**：套餐（¥39.5）装不进 ¥20 预算，自动退回单品；
如实标注超支 ¥5.50，**不硬凑、不忽悠**。
Skill 此时应附加建议：「巨无霸单点需 ¥25.5，超预算 ¥5.5；
可考虑 1+1随心配 ¥13.9（小薯条+小可乐），或改选双层吉士堡 ¥16.5」。

## 附：优惠券试算

```bash
# 订单：巨无霸 + 大薯条 + 大可乐（小计 ¥51.50）
python3 scripts/coupon_matcher.py --items big_mac fries_l coke_l

# 订单：麦辣鸡腿堡套餐 + 冰淇淋（小计 ¥42.50）
python3 scripts/coupon_matcher.py --items mcspicy_combo ice_cream
```

订单 ¥51.50 时：`满50减8`（实省 ¥8.00）优于 `全场85折`（实省 ¥7.73，封顶¥10），
算法正确选出最优券——**折扣券并非永远划算，满减在临界点更香**。
