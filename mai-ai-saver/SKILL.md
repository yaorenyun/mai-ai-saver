# 麦麦省钱助手 🍔

> **Goal**：1024 程序员节的午餐救星——帮用户在麦当劳点餐时"花最少的钱，吃最像样的一顿"。
> 通过麦当劳 MCP 获取实时菜单/优惠/门店数据，用本地优化引擎计算
> 预算内最优搭配，并自动完成"单品 → 套餐"的省钱升档。

## When to Use（触发场景）

用户表达以下任一意图时加载本 Skill：

- **点餐决策**：「麦当劳吃点什么」「帮我配个午餐」「30 块能吃啥」
- **省钱比价**：「怎么点最划算」「单点还是套餐」「这个券值不值」
- **必点确认**：「想吃巨无霸，帮我配一下」「必点麦辣鸡腿堡」
- **偏好约束**：「不吃辣有什么推荐」「要健康低卡的」
- **优惠咨询**：「麦当劳现在有什么券」「满减怎么凑」
- **门店/活动**：「附近麦当劳」「程序员节活动」

## When NOT to Use（不触发）

- 与麦当劳/餐饮消费完全无关的通用对话
- 需要真实下单支付的场景（本 Skill 只做决策建议，不创建订单）
- 价格/优惠与官方不一致时的申诉处理（引导用户以 App 实时显示为准）

## 工作流（五步）

```
用户提出点餐需求
    │
    ▼
1️⃣ 意图解析 ── 提取：预算 / 必点项 / 口味排除 / 人数
    │
    ▼
2️⃣ 数据获取 ── mcp_client.py 查询麦当劳 MCP
    │              ├─ get_menu        菜单与实时价格
    │              ├─ get_coupons     可用优惠券
    │              ├─ get_nearby_stores 附近门店
    │              └─ get_activities  进行中活动
    │              （MCP 不可用 → 自动降级 references/menu-data.json）
    ▼
3️⃣ 组合优化 ── price_optimizer.py
    │              ├─ 必点单品自动升级为含它的套餐（省得更多）
    │              ├─ 约束过滤（预算 / 排除标签）
    │              └─ 有界枚举：满足度 + 餐食完整度双维打分
    ▼
4️⃣ 券后验算 ── coupon_matcher.py 对 TOP 方案试算最优券
    │
    ▼
5️⃣ 输出建议 ── TOP 3 方案对比 + 券后价 + 门店推荐
```

## 脚本使用说明

所有脚本位于 `scripts/`，Python 3.10+ 可直接运行：

```bash
# 组合优化：预算 50，必点巨无霸
python3 scripts/price_optimizer.py --budget 50 --must big_mac

# 优惠券匹配：对订单 big_mac + fries_l + coke_l 试算
python3 scripts/coupon_matcher.py --items big_mac fries_l coke_l

# MCP 数据查询（含离线降级演示）
python3 scripts/mcp_client.py --demo

# 切换真实麦当劳 MCP
export MAI_MCP_COMMAND="npx -y @mcdonalds-china/mcp-server"
python3 scripts/mcp_client.py --demo
```

> 在 WorkBuddy / Agent 环境中，优先由助手直接调用上述脚本并解读结果，
> 而非要求用户手动执行。

## 输出规范（必须遵守）

1. **先给结论**：第一句话直接给出推荐方案与券后总价
2. **对比呈现**：至少给出 2 个方案（预算充裕时给 3 个），标注各自优势
3. **金额透明**：每笔花费列明明细，券后价单独标注；节省金额必须给出计算依据
4. **升档提示**：若必点单品被自动升级为套餐，明确告知"省了多少钱"
5. **风险提示**：预算不足时如实说明超支或降级方案，不硬凑
6. **免责声明**：结尾提醒"价格与优惠以麦当劳 App 实时显示为准"

## 约束与边界

- **不创建订单、不发起支付**——本 Skill 只做消费决策辅助
- **价格数据**：MCP 实时数据优先；离线演示数据仅供参考，不得冒充实时价
- **优惠叠加**：默认按"实省最多的一张券"推荐，多券叠加以 MCP 试算为准
- **健康提醒**：用户连续多轮高油高糖搭配时，轻量提醒均衡饮食（不打断主流程）
